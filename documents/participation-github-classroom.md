# GitHub Classroom Participation

## Overview

Starting in Week 2, each class session has a GitHub Classroom assignment where you submit your in-class work. This is worth **10% of your final grade**.

**The goal:** Keep a personal archive of working code samples from every class to reference for projects and studying.

## How It Works

### Each Class Day:
1. Accept the GitHub Classroom assignment (link posted in MyCourses/Slack)
2. This creates **your personal repo** for today's class (e.g., `week7a-yourusername`)
3. Clone it to your machine OR just use the GitHub website

### During/After Class:
- Follow along with the in-class demonstration
- Work on the exercise at your own pace
- **Don't worry if you don't finish!** Just show good effort and progress

### Before Next Class:
Submit your work using one of two methods below.

---

## Submission Method 1: Copy main.dart Only (Recommended)

**Use GitHub's website - no cloning needed! Takes 30 seconds.**

1. Go to your repo on GitHub.com
2. Click on `main.dart`
3. Click the pencil icon to edit
4. Delete existing code, paste your code from today's class
5. Click **"Commit changes"**
6. Add a commit message like "Completed Week 7A work"
7. Click **"Commit changes"** again

Done! Your code is saved and I can see your progress.

---

## Submission Method 2: Full Flutter Project (Optional)

If you prefer to keep the complete project structure (preserves pubspec.yaml, assets, etc.):

### Using GitHub Desktop:
1. Clone your assignment repo
2. Copy your entire Flutter project folder into the repo
3. Make sure `.gitignore` is present (prevents huge build folders)
4. Commit and push

### Command Line:
```bash
git clone [your-assignment-repo-url]
cd [repo-name]
# Copy your project folder into the repo
git add .
git commit -m "Added Week 7A work"
git push origin main
```

**Important:** The `.gitignore` prevents uploading build files (would be 450+ MB without it!)
