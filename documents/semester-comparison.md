## File Naming Strategy

Weekly files use Fall numbering as the "canonical" names since Fall semesters repeat the same pattern.

| File | Content | Used In |
|------|---------|---------|
| `weekly/8A.md` | Firebase (TBD) | Spring only |
| `weekly/8B.md` | Advanced TextFields | Both |
| `weekly/14A.md` | Lab Day | Fall only |
| `weekly/15A.md` | Camera & ImagePicker | Fall (Week 15), Spring (Week 14) |
| `weekly/15B.md` | Responsive Design | Fall (Week 15), Spring (Week 14) |

The `schedule.md` file maps these lesson files to the correct calendar dates each semester.
