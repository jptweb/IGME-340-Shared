## I. SnackBar Notifications

SnackBars are temporary notifications that pop up from the bottom of the screen and auto-dismiss.

### Basic SnackBar

```dart
ScaffoldMessenger.of(context).showSnackBar(
  SnackBar(
    content: Text('Operation completed'),
  ),
);
```

- `ScaffoldMessenger.of(context)` finds the nearest Scaffold and uses it to show notifications
- Auto-dismisses after about 4 seconds by default
- Multiple SnackBars queue up if triggered rapidly

### Customized SnackBar

You can add an icon, change the background color, control the duration, and add an action button:

```dart
ScaffoldMessenger.of(context).showSnackBar(
  SnackBar(
    content: Row(
      children: [
        Icon(Icons.info, color: Colors.white),
        SizedBox(width: 10),
        Text('File saved successfully'),
      ],
    ),
    backgroundColor: Colors.green,
    duration: Duration(seconds: 10),
    action: SnackBarAction(
      label: 'UNDO',
      textColor: Colors.yellow,
      onPressed: () {
        ScaffoldMessenger.of(context).hideCurrentSnackBar();
      },
    ),
  ),
);
```

**Key Points:**
- `content` takes any widget — use a Row for icon + text
- `duration: Duration(seconds: 10)` overrides the default 4-second timer
- `SnackBarAction` adds a button on the right (label auto-uppercases)
- `hideCurrentSnackBar()` dismisses it immediately

## II. Material Banner

Material Banners appear at the top and are persistent — the user must dismiss them. Use these for important messages that can't be missed.

### Basic MaterialBanner

```dart
ScaffoldMessenger.of(context).showMaterialBanner(
  MaterialBanner(
    content: Text('System update available'),
    actions: [
      TextButton(
        onPressed: () {
          ScaffoldMessenger.of(context).hideCurrentMaterialBanner();
        },
        child: Text('DISMISS'),
      ),
    ],
  ),
);
```

- The `actions` list is **required** — if you leave it empty, you get a runtime error
- `hideCurrentMaterialBanner()` dismisses it

### Banner Stacking Problem & Cascade Fix

Clicking the banner button multiple times creates stacked banners. Fix this with Dart's **cascade notation** (`..`):

```dart
ScaffoldMessenger.of(context)
  ..removeCurrentMaterialBanner()
  ..showMaterialBanner(
    MaterialBanner(
      content: Text('System update available'),
      actions: [
        TextButton(
          onPressed: () {
            ScaffoldMessenger.of(context).hideCurrentMaterialBanner();
          },
          child: Text('DISMISS'),
        ),
      ],
    ),
  );
```

The `..` operator lets you call multiple methods on the same object:
- `..removeCurrentMaterialBanner()` removes any existing banner first
- `..showMaterialBanner(...)` then shows the new one
- Without cascade, you'd need to write `ScaffoldMessenger.of(context)` twice

### Banner Customization

```dart
MaterialBanner(
  content: Text('Welcome to Week 5B!'),
  backgroundColor: Colors.amber.shade100,
  leading: Icon(Icons.warning, color: Colors.orange),
  actions: [
    TextButton(
      onPressed: () {
        ScaffoldMessenger.of(context).hideCurrentMaterialBanner();
      },
      child: Text('DISMISS'),
    ),
  ],
),
```

## III. Item Box Demo — Extract Method & Extract Widget

Before jumping into Project 1 work time, we built a quick item box similar to what you're doing in your project, then used two refactoring techniques to make it reusable.

### The Item Box

A Row with a tappable image (shows a dialog on tap) and scrollable text:

```dart
Row(
  children: [
    InkWell(
      onTap: () {
        showDialog(
          context: context,
          builder: (context) {
            return AlertDialog(
              title: Text("My Title"),
              content: Text("My Full Content"),
            );
          },
        );
      },
      child: Image.network('https://placehold.co/50x50/EEE/31343C.png'),
    ),
    Container(
      height: 50,
      width: 300,
      child: SingleChildScrollView(child: Text(lorem)),
    ),
  ],
),
```

### Extract Method

Select a widget tree, right-click → **Refactor** → **Extract Method**. This pulls the code into a method you can call multiple times.

To make it reusable, add parameters for the parts that change:

```dart
Widget buildItemBox(String title, String content, String imageUrl) {
  // The extracted Row goes here, using title, content, and imageUrl
  // instead of hardcoded values
}
```

Then call it multiple times with different data:

```dart
buildItemBox("Planks", "Oak wood planks...", "assets/images/planks.png"),
buildItemBox("Sticks", "Crafting material...", "assets/images/sticks.png"),
```

### Extract Widget

Select a widget tree, right-click → **Refactor** → **Extract Widget**. This creates a new `StatelessWidget` class with a constructor.

**The trick:** If you move the dynamic parts into variables *before* extracting, VS Code automatically creates constructor parameters for all of them — saving you from writing the constructor by hand.

```dart
// 1. Move dynamic parts to variables
String title = "My Title";
String content = "My Full Content";
String imageUrl = "https://placehold.co/50x50/EEE/31343C.png";

// 2. Use the variables in the widget
Row(
  children: [
    InkWell(
      onTap: () { /* uses title, content */ },
      child: Image.network(imageUrl),
    ),
    Container(/* uses lorem */),
  ],
),

// 3. Extract Widget → VS Code creates constructor params for
//    title, content, imageUrl, and lorem automatically
```

Once extracted, you can also **move the widget to its own file**: click the class name → Refactor → Move to file. The import is added automatically.

### Extract Method vs Extract Widget

| | Extract Method | Extract Widget |
|---|---|---|
| Creates | A method in the same class | A new StatelessWidget class |
| Reuse | Within the same widget | Anywhere in the app |
| Own file | No (stays in same class) | Yes (can move to separate file) |
| Best for | Quick reuse in one screen | Reusable components across screens |

Both approaches earn the [Project 1 code organization bonus](../projects/design_to_spec.md#iv-code-organization-bonus-5-points).

## V. Common Issues & Solutions

| Problem | Solution |
|---------|----------|
| "No ScaffoldMessenger found" | Ensure widget is inside MaterialApp with a Scaffold |
| Material banners stack up | Chain `..removeCurrentMaterialBanner()` before showing new |
| Banner won't dismiss | Check you're calling `hideCurrentMaterialBanner()` (not SnackBar version) |
| SnackBar appears too briefly | Increase `duration` or add an action button |
| Actions required error | MaterialBanner requires at least one widget in `actions` list |
| Extract Method has no parameters | Add them manually to the method signature |
| Extract Widget missing a param | Move the value to a variable before extracting |
