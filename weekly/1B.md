### Lists (Arrays)
```dart
// Creating lists
var fruits = ["apple", "banana", "orange"];
List<int> numbers = [1, 2, 3, 4, 5];

// List operations
fruits.add("grape");
fruits.remove("banana");
fruits.insert(1, "mango");

// Iteration
for (var fruit in fruits) {
  print(fruit);
}
fruits.forEach((fruit) => print(fruit));
```

### Maps (Dictionaries)
```dart
// Creating maps
var student = {
  "name": "Alice",
  "major": "NMID",
  "year": 3
};

// Map operations
student["gpa"] = 3.8;
student.remove("year");

// Iteration
student.forEach((key, value) {
  print("$key: $value");
});
```

### Functions
```dart
// Basic function
int add(int a, int b) {
  return a + b;
}

// Arrow function
int multiply(int a, int b) => a * b;

// Named parameters
void createCharacter({
  required String name,
  int health = 100,
  String? weapon
}) {
  print("$name has $health HP");
}

// Call with named parameters
createCharacter(name: "Hero", weapon: "Sword");
```

### Key Takeaways
- Dart syntax is similar to Java/JavaScript
- Strong typing helps catch errors early
- Collections are powerful and flexible
- DartPad is great for practice without setup
