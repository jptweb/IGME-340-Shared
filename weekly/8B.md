## Initial Plan

Today we'll build a small app that ties together several things you've learned:

### What We'll Cover

1. **Using a practice API (DummyJSON or similar)**
   - Making GET requests to a public API
   - Parsing the JSON response into usable Dart objects

2. **TextField-driven API requests**
   - A search TextField where the user's input gets injected into the API endpoint URL
   - Triggering a fetch when the user submits their search
   - Displaying the results below the search field

3. **Putting it all together**
   - Connecting the pieces: user input → API call → display data
   - This is exactly the pattern you'll use in GIF Finder and Project 2
