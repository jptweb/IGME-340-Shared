## I. The `image_picker` Package

**Package:** https://pub.dev/packages/image_picker/

This is the most downloaded image/video picking package for Flutter. It provides a cross-platform way to:
- Take photos with the camera
- Record videos with the camera
- Pick images from the gallery

Even though the example code has `import` statements, you still need to manually install the packages. The imports tell Dart what to use, but the packages must be downloaded first.

## IV. Android Emulator Camera Setup

The Android emulator can simulate a camera in different ways. This is useful for testing without a physical device.

### Where to Configure Camera Settings

**Important:** Camera settings are configured in **Android Studio's Device Manager**, NOT in the running emulator!

1. Open **Android Studio**
2. Go to **Device Manager** (in the right sidebar, or View → Tool Windows → Device Manager)
3. Find your emulator device and click the **pencil icon** (Edit)
4. Look for the **Camera** section with Front/Rear dropdowns

You'll see options like:
- **Front**: Emulated, VirtualScene, Webcam0, None
- **Rear**: Emulated, VirtualScene, Webcam0, None

### ❌ Skip "Emulated" Mode

When you create a new emulator, it may default to **"Emulated"** for the front camera. This shows a weird green/checkered space that isn't very useful for testing. We recommend changing this.

### ✅ Option A: Virtual Scene (Recommended for Testing)

The **VirtualScene** option provides a virtual 3D environment you can "walk" through - great for testing camera features!

**Setup:**
1. In Device Manager, set **Front** and/or **Rear** camera to **VirtualScene**
2. Click **Finish** to save
3. Start (or restart) the emulator

**Controls for Walking Around:**

⚠️ **Important:** By default, you can't walk around! You need to enable mouse look mode:

- **Hold Option key (Mac) or Alt key (Windows/Linux)** - This enables mouse look mode
- While holding Option/Alt:
  - **WASD keys** - Move forward/back/left/right
  - **Mouse movement** - Look around
  - **Q/E keys** - Move up/down

*Without holding Option/Alt, WASD won't work for movement!*

**Tip:** Click inside the emulator window first to ensure it has keyboard focus.

**Fun Feature - Custom Wall Image:**

The Virtual Scene has a dining room with a picture frame on the wall! You can display your own image there:

1. In the running emulator, click **...** (Extended Controls) in the toolbar
2. Go to **Camera** → **Virtual Scene**
3. Click **Add Image** and select a photo from your computer
4. Walk into the dining room (use Option/Alt + WASD) to see it on the wall!

⚠️ **Note:** Large images (like full-resolution photos from Pexels) may not display. Use a smaller image or screenshot instead - it needs to fit in the picture frame!

### ✅ Option B: Webcam Passthrough

Use your computer's actual webcam as the emulator's camera - great for testing with real camera input!

**Setup:**
1. In Device Manager, set **Front** or **Rear** camera to **Webcam0** (or your webcam name)
2. Click **Finish** to save
3. Start (or restart) the emulator

**Troubleshooting Webcam:**
- If webcam doesn't appear as an option:
  - Close other apps using the webcam (Zoom, Teams, etc.)
  - Restart Android Studio
  - Check that your webcam works in other apps first

### Summary: Recommended Settings

| Camera | Setting | Why |
|--------|---------|-----|
| **Front** | VirtualScene or Webcam0 | Avoid "Emulated" (weird green space) |
| **Rear** | VirtualScene | Good for testing, can walk around |

## V. Exploring the Example Code

The pub.dev example includes:

### Image Picking
- `pickImage()` - Pick from gallery
- `pickMultiImage()` - Pick multiple images
- Take photo with camera

### Video Features
- Pick video from gallery
- Record video with camera
- Video playback with `video_player`

### Key Concepts to Notice

1. **Async/Await** - Camera operations are asynchronous
2. **Null Safety** - Handling cases where user cancels
3. **Platform Checks** - Different behavior for web vs mobile
4. **State Management** - Updating UI after picking media

### Code Walkthrough Points

```dart
// The ImagePicker instance
final ImagePicker _picker = ImagePicker();

// Picking a single image
final XFile? image = await _picker.pickImage(source: ImageSource.gallery);

// Picking from camera
final XFile? photo = await _picker.pickImage(source: ImageSource.camera);

// Picking video
final XFile? video = await _picker.pickVideo(source: ImageSource.camera);
```

## VI. Common Issues & Solutions

### "No camera available"
- Emulator camera not configured (see Section IV)
- Permissions not granted - check app settings

### Red squiggles on imports
- Package not installed - run `flutter pub add package_name`
- Run `flutter pub get` after adding packages

### Video not playing
- `video_player` package not installed
- Video format not supported

### Webcam not showing in emulator options
- Another app is using the webcam
- Try restarting Android Studio / emulator
- Update Android SDK tools

## Simplified Example (Reference)

If you want a minimal starting point instead of the full pub.dev example, here's a simple version with just photo capture:

```dart
import 'package:flutter/material.dart';
import 'package:image_picker/image_picker.dart';
import 'dart:io';

void main() => runApp(const MyApp());

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: const ImagePickerDemo(),
    );
  }
}

class ImagePickerDemo extends StatefulWidget {
  const ImagePickerDemo({super.key});

  @override
  State<ImagePickerDemo> createState() => _ImagePickerDemoState();
}

class _ImagePickerDemoState extends State<ImagePickerDemo> {
  File? _image;
  final ImagePicker _picker = ImagePicker();

  Future<void> _takePhoto() async {
    final XFile? photo = await _picker.pickImage(source: ImageSource.camera);
    if (photo != null) {
      setState(() {
        _image = File(photo.path);
      });
    }
  }

  Future<void> _pickFromGallery() async {
    final XFile? image = await _picker.pickImage(source: ImageSource.gallery);
    if (image != null) {
      setState(() {
        _image = File(image.path);
      });
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Image Picker Demo')),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            if (_image != null)
              Image.file(_image!, height: 300)
            else
              const Text('No image selected'),
            const SizedBox(height: 20),
            ElevatedButton(
              onPressed: _takePhoto,
              child: const Text('Take Photo'),
            ),
            ElevatedButton(
              onPressed: _pickFromGallery,
              child: const Text('Pick from Gallery'),
            ),
          ],
        ),
      ),
    );
  }
}
```
