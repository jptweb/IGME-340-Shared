- Create and run the default counter app

**Stuck?** The [Flutter/Android Studio Installation Video](https://rit.zoom.us/rec/share/2tWwgzLXa6K0GoC5oepJK7WMSTiAtcFA2GsZn7KDwBfft24cv97DAjQBksONHCRg.RtLP4wUAPsH02U7u) (~40 min) walks through the full VS Code install flow.
