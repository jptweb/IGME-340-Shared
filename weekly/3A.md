# Week 3A - Flutter Layout Widgets

## What We Covered in Class

### Container Widget Fundamentals
We explored the Container widget, which is the most basic building block in Flutter layouts. Containers can hold content, apply styling, and control sizing behavior. We discovered that containers without children expand to fill all available space, but shrink to fit their content when a child is added.

**Key Points:**
- Containers without explicit size fill their parent
- Adding a child causes the container to wrap content size
- Use `double.infinity` for full width/height (like CSS 100%)
- Containers need positioning widgets (Center, Align) to respect size constraints

### Column and Row Layouts
We learned how to arrange multiple widgets vertically using Column and horizontally using Row. These fundamental layout widgets use a children property (list) instead of a single child, allowing multiple widgets to be organized together.

**What We Did:**
- Created columns with multiple colored containers
- Applied `mainAxisAlignment` to control vertical positioning
- Added spacing between items using the new `spacing` property
- Discovered that columns size themselves to their largest child

### Handling Overflow with ScrollView
When adding too many widgets caused overflow errors (yellow/black striped warning), we learned that Flutter doesn't automatically add scrolling. We wrapped our Column in a SingleChildScrollView to enable scrolling behavior.

**What We Did:**
- Identified overflow issues when content exceeds screen space  
- Used `Cmd/Ctrl + Period` to wrap widgets quickly
- Added SingleChildScrollView for vertical scrolling
- Noticed iOS-style elastic bounce effect

## Key Concepts & Terminology

| Term | Definition |
|------|------------|
| Container | Basic widget that can contain a child, apply decoration, and control size |
| Column | Arranges children vertically in a linear array |
| Row | Arranges children horizontally in a linear array |
| EdgeInsets | Controls padding/margin spacing around widgets |
| MainAxisAlignment | Controls positioning along the main axis (vertical for Column, horizontal for Row) |
| SingleChildScrollView | Enables scrolling when content exceeds available space |
| double.infinity | Makes a widget take up all available space in a dimension |

## Common Issues & Solutions

| Problem | Solution |
|---------|----------|
| Container fills entire screen unexpectedly | Add explicit width/height or wrap in Center widget |
| Yellow/black overflow stripes appear | Wrap Column/Row in SingleChildScrollView |
| Inner container size being ignored | Parent needs positioning widget (Center, Align) |
| Code won't auto-format | Add trailing commas after closing parentheses |
| Horizontal scroll not working with Row | Known issue - instructor investigating fix |

## Code/Commands from Class

```dart
// Basic container with sizing
Container(
  color: Colors.pink,
  width: 300,
  height: 300,
  child: Text('Hello World Week 3'),
)

// Column with spacing (new feature)
Column(
  mainAxisAlignment: MainAxisAlignment.center,
  spacing: 30,  // New spacing property
  children: [
    Container(color: Colors.blue, height: 200),
    Container(color: Colors.green, height: 150),
  ],
)

// Adding scroll capability
SingleChildScrollView(
  child: Column(
    children: [...],
  ),
)

// Keyboard shortcuts used
Cmd/Ctrl + Period  // Widget manipulation menu
Alt/Shift + F      // Auto-format code (needs trailing commas)
```

## Key Takeaways

1. **Container sizing behavior** - Understanding when containers expand vs shrink is crucial for layouts
2. **Widget wrapping shortcuts** - Use `Cmd/Ctrl + Period` to quickly manipulate widget hierarchy  
3. **Explicit scrolling required** - Flutter doesn't auto-scroll; must wrap with ScrollView widgets
