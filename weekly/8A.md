## What We Covered in Class

### Part 1: The Problem with Hard-Coded Widths

When building layouts with Rows, you often end up guessing widths for containers. We built an Image - Text - Image row layout to see this in action:

```dart
Row(
  children: [
    Container(
      width: 100,
      height: 100,
      decoration: BoxDecoration(
        border: Border.all(width: 4, color: Colors.green),
      ),
      child: Image.network('https://placehold.co/100x100/png'),
    ),
    SizedBox(width: 20),
    Container(
      width: 250,  // GUESSED width - the problem!
      height: 100,
      decoration: BoxDecoration(
        border: Border.all(width: 4, color: Colors.red),
      ),
      child: SingleChildScrollView(
        child: Text(bulkText),
      ),
    ),
  ],
)
```

This looks okay at first, but try rotating the device:
- **Portrait mode:** Might look fine
- **Landscape mode:** Text gets cut off OR has a huge empty gap
- **Different devices:** Breaks on tablets or small phones

Hard-coded widths don't adapt. This is the #1 reason apps look unprofessional.

---

### Part 2: The Solution - Expanded Widget in Rows

The `Expanded` widget fills ALL remaining horizontal space automatically. We removed the hard-coded `width: 250` and wrapped the middle container in `Expanded`:

```dart
Row(
  children: [
    Container(
      width: 100,
      height: 100,
      decoration: BoxDecoration(
        border: Border.all(width: 4, color: Colors.green),
      ),
      child: Image.network('https://placehold.co/100x100/png'),
    ),
    SizedBox(width: 20),
    Expanded(
      child: Container(
        height: 100,  // Only height needed now!
        decoration: BoxDecoration(
          border: Border.all(width: 4, color: Colors.red),
        ),
        child: SingleChildScrollView(
          child: Text(bulkText),
        ),
      ),
    ),
    SizedBox(width: 20),
    Container(
      width: 100,
      height: 100,
      decoration: BoxDecoration(
        border: Border.all(width: 4, color: Colors.green),
      ),
      child: Image.network('https://placehold.co/100x100/png'),
    ),
  ],
)
```

**What Happens:**
- Expanded calculates: `remaining width = screen width - 100 - 20 - 100 - 20`
- The text container fills exactly the right amount of space
- Rotate the device? It recalculates automatically

### Part 3: Expanded in Columns (Vertical Space)

Expanded also works vertically inside a `Column`. We added a container below the Row and tried to make it fill the rest of the screen.

**First attempt — just a plain Container:**

```dart
Column(
  children: [
    Row(/* image-text-image row from above */),
    Container(
      color: Colors.amber,
      child: Text("Here is some More Text"),
    ),
  ],
)
```

It only takes up as much space as the text needs. Not what we want.

**Try `height: double.infinity`?** Nope — the Column won't let a child be infinitely tall.

**The fix — wrap it in Expanded:**

```dart
Column(
  children: [
    Row(/* image-text-image row from above */),
    Expanded(
      child: Container(
        color: Colors.amber,
        child: Text("Here is some More Text"),
      ),
    ),
  ],
)
```

Now it fills all remaining vertical space!

**One more thing:** The width still only takes up as much space as the text. Expanded stretches in the direction its parent lays out (vertical for Column), but you may still need `width: double.infinity` for the cross-axis:

```dart
Expanded(
  child: Container(
    width: double.infinity,
    color: Color.fromARGB(119, 166, 185, 168),
    child: Text("Here is some More Text"),
  ),
),
```

Now it fills the entire remaining space — both vertically AND horizontally.

---

### Key Takeaway

| Situation | What Expanded Does |
|-----------|--------------------|
| Inside a `Row` | Fills remaining **horizontal** space |
| Inside a `Column` | Fills remaining **vertical** space |
| Cross-axis (the other direction) | Use `width: double.infinity` or `height` as needed |

**Use Cases:**
- Responsive image-text layouts that adapt to screen rotation
- Content areas that fill available screen height
- Any layout where you'd otherwise be guessing pixel values
