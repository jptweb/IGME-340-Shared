## Part 1: CachedNetworkImage Package

### Why We Need This
Regular `Image.network()` downloads the image EVERY time the widget rebuilds. For a 2MB image, that's wasteful on mobile data and slow on poor connections. `CachedNetworkImage` downloads once and stores it locally.

### Installation
```bash
flutter pub add cached_network_image
```

### Import
```dart
import 'package:cached_network_image/cached_network_image.dart';
```

### The Demo We Built

**Step 1:** We added a string variable for our test image (a large 2MB image):

```dart
class _HomePageState extends State<HomePage> {
  String myImage = "https://people.rit.edu/~dxcigm/340/assets/images/nms_big.jpg";
  
  @override
  Widget build(BuildContext context) {
    // ... scaffold code
  }
}
```

**Step 2:** We added a regular network image first (for comparison):

```dart
// Inside Column children
Image.network(
  myImage,
  width: 200,
  height: 200,
),
const SizedBox(height: 20),
```

**Step 3:** Then we added the cached version:

```dart
CachedNetworkImage(
  imageUrl: myImage,
  width: 200,
  height: 200,
),
const SizedBox(height: 20),
```

**Step 4:** We demonstrated the difference by hot restarting - the cached image loaded instantly!

**Step 5:** We showed how to use it with Container decorations:

```dart
Container(
  width: 200,
  height: 200,
  decoration: BoxDecoration(
    image: DecorationImage(
      image: CachedNetworkImageProvider(myImage),
      fit: BoxFit.cover,
    ),
  ),
),
const SizedBox(height: 20),
```

**Step 6:** Finally, we added professional loading and error handling:

```dart
CachedNetworkImage(
  imageUrl: myImage,
  width: 200,
  height: 200,
  placeholder: (context, url) => const CircularProgressIndicator(),
  errorWidget: (context, url, error) => const Icon(Icons.error),
),
```

**What You Should Understand:**
- Use `CachedNetworkImage` widget for simple image display
- Use `CachedNetworkImageProvider` for Container decorations
- Always add placeholder and error widgets for professional UX

## Part 2: SharedPreferences Package

### Why We Need This
SharedPreferences lets you save simple data persistently on the device (like localStorage in web dev). Perfect for settings, preferences, favorites, etc.

### Installation
```bash
flutter pub add shared_preferences
```

### Import
```dart
import 'package:shared_preferences/shared_preferences.dart';
```

### The Demo We Built

**Step 1:** We added a variable to track saved text:

```dart
class _HomePageState extends State<HomePage> {
  String myImage = "https://people.rit.edu/~dxcigm/340/assets/images/nms_big.jpg";
  String savedText = "No text saved yet";  // Add this
  
  // ... rest of class
}
```

**Step 2:** We created a method to save data:

```dart
Future<void> saveData(String value) async {
  final prefs = await SharedPreferences.getInstance();
  await prefs.setString('myKey', value);
  setState(() {
    savedText = "Saved: $value";
  });
}
```

**Step 3:** We created a method to load data:

```dart
Future<void> loadData() async {
  final prefs = await SharedPreferences.getInstance();
  final value = prefs.getString('myKey') ?? 'No data found';
  setState(() {
    savedText = value;
  });
}
```

**Step 4:** We added UI elements to test it (add these to your Column):

```dart
Padding(
  padding: const EdgeInsets.all(16.0),
  child: Column(
    children: [
      TextField(
        decoration: const InputDecoration(
          hintText: 'Enter text to save',
          border: OutlineInputBorder(),
        ),
        onSubmitted: (value) {
          saveData(value);
        },
      ),
      const SizedBox(height: 10),
      ElevatedButton(
        onPressed: loadData,
        child: const Text('Load Saved Data'),
      ),
      const SizedBox(height: 10),
      Text(savedText),
    ],
  ),
),
```

**How We Tested It:**
1. Typed text in the field and pressed Enter
2. Hot restarted the entire app
3. Clicked "Load Saved Data" button
4. The text we entered was still there! 🎉

**Other Data Types You Can Save:**
```dart
// Save
await prefs.setInt('counter', 42);
await prefs.setDouble('price', 19.99);
await prefs.setBool('isLoggedIn', true);
await prefs.setStringList('favorites', ['cat', 'dog', 'bird']);

// Load (with defaults)
final counter = prefs.getInt('counter') ?? 0;
final price = prefs.getDouble('price') ?? 0.0;
final isLoggedIn = prefs.getBool('isLoggedIn') ?? false;
final favorites = prefs.getStringList('favorites') ?? [];
```

**Important Notes:**
- All SharedPreferences methods are `async` - don't forget `await`!
- Always provide a default value with `??` when loading
- Can't save complex objects directly (need to convert to String/JSON first)

## Part 3: URL Launcher Package

### Why We Need This
URL Launcher opens external apps and resources: web browsers, phone dialers, email clients, SMS, etc. Essential for linking to external content.

### Installation
```bash
flutter pub add url_launcher
```

### Import
```dart
import 'package:url_launcher/url_launcher.dart';
```

### The Demo We Built

**Step 1:** We added a URL variable:

```dart
class _HomePageState extends State<HomePage> {
  String myImage = "https://people.rit.edu/~dxcigm/340/assets/images/nms_big.jpg";
  String savedText = "No text saved yet";
  String myURL = "https://www.google.com";  // Add this
  
  // ... rest of class
}
```

**Step 2:** We created a method to open the URL:

```dart
Future<void> openURL() async {
  Uri url = Uri.parse(myURL);  // Must convert String to URI!
  
  if (!await launchUrl(url, mode: LaunchMode.inAppWebView)) {
    throw 'Could not launch $url';
  }
}
```

**Step 3:** We added a button to test it (add to Column):

```dart
ElevatedButton(
  onPressed: openURL,
  child: const Text('Open Google'),
),
```

**What Happened:** Clicking the button opened Google inside our app!

**Launch Modes We Discussed:**
```dart
// inAppWebView - Opens inside your app (RECOMMENDED)
mode: LaunchMode.inAppWebView

// inAppBrowserView - Opens in Chrome/Safari within your app  
mode: LaunchMode.inAppBrowserView

// externalApplication - Opens default browser (takes user out)
mode: LaunchMode.externalApplication
```

**Other URL Schemes:**
```dart
// Phone call
Uri.parse('tel:+15855551234')

// Email
Uri.parse('mailto:support@example.com?subject=Help&body=Hi')

// Text message
Uri.parse('sms:+15855551234?body=Hello')
```

**Important Notes:**
- MUST convert String to URI using `Uri.parse()`
- Don't forget `await` before `launchUrl()`
- If simulator can't connect, try cold booting it

## Troubleshooting Tips from Class

**Simulator Network Issues:**
- If network stops working, cold boot the simulator (completely shut down and restart)
- This happened during class and we fixed it by restarting

**Common Mistakes:**
- Forgetting `async` keyword on methods
- Forgetting `await` before async operations
- Not providing default values with `??` when loading from SharedPreferences
- Trying to use String instead of URI with url_launcher

## Key Concepts & Terminology

| Term | Definition |
|------|------------|
| Caching | Storing downloaded data locally to avoid re-downloading |
| Persistent Storage | Data that remains even after app closes |
| Key-Value Store | Storage system using keys to save/retrieve values |
| Async Operation | Operation that takes time and doesn't block the app |
| URI | Uniform Resource Identifier - standardized format for URLs |
| Launch Mode | How a URL opens (in-app, external, etc.) |
