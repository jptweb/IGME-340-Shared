## Part 1: CachedNetworkImage Package

### Why We Need This
Regular `Image.network()` downloads the image EVERY time the widget rebuilds. For a 2MB image, that's wasteful on mobile data and slow on poor connections. `CachedNetworkImage` downloads once and stores it locally.

### Installation
```bash
flutter pub add cached_network_image
```

### Import
```dart
import 'package:cached_network_image/cached_network_image.dart';
```

### The Demo We Built

**Step 1:** We added a string variable for our test image (a large 2MB image):

```dart
class _HomePageState extends State<HomePage> {
  String myImage = "https://people.rit.edu/~dxcigm/340/assets/images/nms_big.jpg";
  
  @override
  Widget build(BuildContext context) {
    // ... scaffold code
  }
}
```

**Step 2:** We added a regular network image first (for comparison):

```dart
// Inside Column children
Image.network(
  myImage,
  width: 200,
  height: 200,
),
const SizedBox(height: 20),
```

**Step 3:** Then we added the cached version:

```dart
CachedNetworkImage(
  imageUrl: myImage,
  width: 200,
  height: 200,
),
const SizedBox(height: 20),
```

**Step 4:** We demonstrated the difference by hot restarting - the cached image loaded instantly!

**Step 5:** We showed how to use it with Container decorations:

```dart
Container(
  width: 200,
  height: 200,
  decoration: BoxDecoration(
    image: DecorationImage(
      image: CachedNetworkImageProvider(myImage),
      fit: BoxFit.cover,
    ),
  ),
),
const SizedBox(height: 20),
```

**Step 6:** Finally, we added professional loading and error handling:

```dart
CachedNetworkImage(
  imageUrl: myImage,
  width: 200,
  height: 200,
  placeholder: (context, url) => const CircularProgressIndicator(),
  errorWidget: (context, url, error) => const Icon(Icons.error),
),
```

**What You Should Understand:**
- Use `CachedNetworkImage` widget for simple image display
- Use `CachedNetworkImageProvider` for Container decorations
- Always add placeholder and error widgets for professional UX

## Part 2: SharedPreferences Package

### Why We Need This
Apps need to remember user preferences and data between sessions. SharedPreferences provides simple key-value storage that persists even after closing the app - similar to web localStorage.

### Installation
```bash
flutter pub add shared_preferences
```

### Import
```dart
import 'package:shared_preferences/shared_preferences.dart';
```

### The Demo We Built

**Step 1:** We created two TextEditingControllers for our demo form:

```dart
class _HomePageState extends State<HomePage> {

  final txtController01 = TextEditingController();  // Add these
  final txtController02 = TextEditingController();
  
  // ... rest of class
}
```

**Step 2:** We added two TextField widgets to our Column:

```dart

const SizedBox(height: 20),
```

**Step 3:** We declared a `late` SharedPreferences variable (since we'll initialize it later):

```dart
class _HomePageState extends State<HomePage> {
  String myImage = "https://people.rit.edu/~dxcigm/340/assets/images/nms_big.jpg";
  final txtController01 = TextEditingController();
  final txtController02 = TextEditingController();
  late SharedPreferences myPrefs;  // Add this
  
  // ... rest of class
```

**Step 4:** We created an async init function and called it from initState:

```dart
@override

  super.initState();
  init();  // Call our initialization
}

Future<void> init() async {
  myPrefs = await SharedPreferences.getInstance();
}
```

**Why?** `initState()` can't be async, so we create a separate async function to initialize SharedPreferences.

**Step 5:** We created a save function:

```dart
Future<void> saveText() async {
  await myPrefs.setString('name', txtController01.text);
  await myPrefs.setString('email', txtController02.text);
}
```

**Step 6:** We added a Save button to call this function:

```dart

  onPressed: saveText,
  child: const Text('Save'),
),
const SizedBox(height: 10),
```

**Step 7:** We created a load function with setState:

```dart
Future<void> loadText() async {
  String name = myPrefs.getString('name') ?? '';
  String email = myPrefs.getString('email') ?? '';
  
  setState(() {
    txtController01.text = name;
    txtController02.text = email;
  });
}
```

**Key Points:**
- `getString('key')` retrieves saved values
- `?? ''` provides an empty string as default if nothing was saved
- `setState()` is required when updating text field values

**Step 8:** We added a Load button:

```dart
ElevatedButton(
  onPressed: loadText,
  child: const Text('Load'),
),
const SizedBox(height: 20),
```

**Step 9:** Don't forget to dispose controllers!

```dart
@override
void dispose() {
  txtController01.dispose();
  txtController02.dispose();
  super.dispose();
}
```

**What You Should Understand:**
- SharedPreferences uses key-value pairs (like a Map)
- Data persists between app sessions
- Available data types: `setString()`, `setInt()`, `setBool()`, `setDouble()`, `setStringList()`
- Always use `?? defaultValue` when loading to handle missing keys
- Must use `setState()` when updating UI with loaded data

**Real-World Uses:**
- Saving last search term (required for Project 2!)
- User preferences (theme, language, settings)
- Simple form data persistence
- App state between sessions

### Advanced: Storing JSON/Map Data
> WARNING: I PROBABLY WILL SKIP THIS IN CLASS BUT IT IS IMPORTANT TOPIC. Just worried about time. But if there is time I will do it; otherwise id strongly suggest working this into your 9A coding from class that you submit! all the steps and code is here
SharedPreferences can only store simple types (String, int, bool, etc.). But what if you want to save complex data like search settings or user preferences all together?

**The Problem:** You CANNOT directly save a Map to SharedPreferences  
**The Solution:** Convert your Map to a JSON string, save it, then convert it back!

**Example: Saving Search Settings**

**Step 1:** Create a Map with your complex data:

```dart
Map<String, dynamic> jsonToSave = {
  'searchTerm': 'cats',
  'maxResults': 20,
  'rating': 'G',
};
```

**Step 2:** In your save function, encode it to a string:

```dart
Future<void> saveText() async {
  // Save regular text fields
  await myPrefs.setString('name', txtController01.text);
  await myPrefs.setString('email', txtController02.text);
  
  // Save JSON data - convert Map to String first!
  String str2save = jsonEncode(jsonToSave);
  await myPrefs.setString('jData', str2save);
}
```

**Step 3:** In your load function, decode it back to a Map:

```dart
Future<void> loadText() async {
  // Load regular text fields
  String name = myPrefs.getString('name') ?? '';
  String email = myPrefs.getString('email') ?? '';
  
  setState(() {
    txtController01.text = name;
    txtController02.text = email;
    
    // Load and decode JSON data
    String? jData = myPrefs.getString('jData');
    if (jData != null) {
      Map<String, dynamic> myMap = jsonDecode(jData);
      // Now you can use the data from the map!
      print('Search term: ${myMap['searchTerm']}');
      print('Max results: ${myMap['maxResults']}');
      print('Rating: ${myMap['rating']}');
    }
  });
}
```

**Critical Points:**
- You MUST use `jsonEncode()` to convert Map → String before saving
- You MUST use `jsonDecode()` to convert String → Map after loading
- This works exactly like web storage in JavaScript!
- Don't forget to import: `import 'dart:convert';` (for jsonEncode/jsonDecode)

**Why This Matters for Project 2:**

Instead of saving 5 individual preferences separately:
```dart
await myPrefs.setString('searchTerm', 'pokemon');
await myPrefs.setInt('resultLimit', 25);
await myPrefs.setString('sortOrder', 'alphabetical');
// ... etc
```

You can save them all in ONE JSON object:
```dart
Map<String, dynamic> searchSettings = {
  'lastSearchTerm': 'pokemon',
  'resultLimit': 25,
  'sortOrder': 'alphabetical',
  'filterType': 'fire',
  'showFavorites': true,
};

String encoded = jsonEncode(searchSettings);
await myPrefs.setString('allSettings', encoded);
```

Then load them all at once:
```dart
String? saved = myPrefs.getString('allSettings');
if (saved != null) {
  Map<String, dynamic> settings = jsonDecode(saved);
  // Use settings['lastSearchTerm'], settings['resultLimit'], etc.
}
```

**Debugging Tip:** You can inspect what's stored in SharedPreferences by setting a breakpoint and looking at `myPrefs` in the debugger - you'll see a `preferenceCache` with all your saved data!

## Part 3: URL Launcher Package

### Why We Need This
URL Launcher opens external apps and resources: web browsers, phone dialers, email clients, SMS, etc. Essential for linking to external content.

### Installation
```bash
flutter pub add url_launcher
```

### Import
```dart
import 'package:url_launcher/url_launcher.dart';
```

### The Demo We Built

**Step 1:** We added a URL variable:

```dart
class _HomePageState extends State<HomePage> {
  String myImage = "https://people.rit.edu/~dxcigm/340/assets/images/nms_big.jpg";
  final txtController01 = TextEditingController();
  final txtController02 = TextEditingController();
  late SharedPreferences myPrefs;
  String myURL = "https://www.google.com";  // Add this
  
  // ... rest of class
}
```

**Step 2:** We created a method to open the URL:

```dart
Future<void> openURL() async {
  Uri url = Uri.parse(myURL);  // Must convert String to URI!
  
  if (!await launchUrl(url, mode: LaunchMode.inAppWebView)) {
    throw 'Could not launch $url';
  }
}
```

**Step 3:** We added a button to test it (add to Column):

```dart
ElevatedButton(
  onPressed: openURL,
  child: const Text('Open Google'),
),
```

**What Happened:** Clicking the button opened Google inside our app!

**Launch Modes We Discussed:**
```dart
// inAppWebView - Opens inside your app (RECOMMENDED)
mode: LaunchMode.inAppWebView

// inAppBrowserView - Opens in Chrome/Safari within your app  
mode: LaunchMode.inAppBrowserView

// externalApplication - Opens default browser (takes user out)
mode: LaunchMode.externalApplication
```

**Other URL Schemes:**
```dart
// Phone call
Uri.parse('tel:+15855551234')

// Email
Uri.parse('mailto:support@example.com?subject=Help&body=Hi')

// Text message
Uri.parse('sms:+15855551234?body=Hello')
```

**Important Notes:**
- MUST convert String to URI using `Uri.parse()`
- Don't forget `await` before `launchUrl()`
- If simulator can't connect, try cold booting it

## Troubleshooting Tips from Class

**Simulator Network Issues:**
- If network stops working, cold boot the simulator (completely shut down and restart)
- This happened during class and we fixed it by restarting

**Common Mistakes:**
- Forgetting `async` keyword on methods
- Forgetting `await` before async operations
- Not providing default values with `??` when loading from SharedPreferences
- Trying to use String instead of URI with url_launcher
- Forgetting to import `dart:convert` when using jsonEncode/jsonDecode

## Key Concepts & Terminology

| Term | Definition |
|------|------------|
| Caching | Storing downloaded data locally to avoid re-downloading |
| Persistent Storage | Data that remains even after app closes |
| Key-Value Store | Storage system using keys to save/retrieve values |
| Async Operation | Operation that takes time and doesn't block the app |
| URI | Uniform Resource Identifier - standardized format for URLs |
| Launch Mode | How a URL opens (in-app, external, etc.) |
| JSON Encoding | Converting Map/object to String for storage |
| JSON Decoding | Converting String back to Map/object |
