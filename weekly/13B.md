## Part 1: Custom App Icons

Each platform needs its icon in a pile of sizes. Android wants 5-7 resolutions (the mipmap folders: mdpi, hdpi, xhdpi, xxhdpi, xxxhdpi), iOS wants 10+ sizes for different devices, and the shapes differ (Android has round icons (12+), iOS has rounded squares). Instead of making those by hand, we'll use **easyappicon.com** to generate all of them from one image.

### Step 4: Replace Android Icons

**Location in your project:**
```
your_project/
└── android/
    └── app/
        └── src/
            └── main/
                └── res/    ← We're working here!
                    ├── mipmap-hdpi/
                    ├── mipmap-mdpi/
                    ├── mipmap-xhdpi/
                    ├── mipmap-xxhdpi/
                    └── mipmap-xxxhdpi/
```

**Two valid ways to do this. Pick ONE.**

easyappicon.com now includes a `values/ic_launcher_background.xml` file in its download (needed for Android v26+ adaptive icons). Pick one path below and stick with it. Mixing them is what causes the duplicate resource build error.

**The rule:** exactly one file in `android/app/src/main/res/values/` should declare the `ic_launcher_background` color. Zero files = "resource not found" build error. Two files = "duplicate resource" build error. One = happy build.

**Path A: Use everything from the download (simpler)**

Good if you're happy with the background color you picked and just want it to work.

1. Open your project's `android/app/src/main/res/` folder in Finder/Explorer (in VS Code, right-click `android/app/src/main/res` → "Reveal in Finder/Explorer")
2. Open the downloaded `android/` folder from easyappicon.com
3. Select **everything** inside it (all the `mipmap-*` folders AND the `values/` folder) and drag them into your project's `res/` folder
4. When asked "Replace?", say **YES to all**
5. **Verify:** you should now see `values/ic_launcher_background.xml` inside your project's `res/values/` folder. It defines the adaptive icon background color (the hex you picked in Step 3).

**If you take Path A, skip Step 5** and go straight to Step 6.

**Path B: Only copy mipmaps, write your own colors.xml (more control)**

Good if you want to set the adaptive icon background hex yourself, or want to see the XML.

1. Open your project's `android/app/src/main/res/` folder in Finder/Explorer
2. Open the downloaded `android/` folder from easyappicon.com
3. Drag **only** the `mipmap-*` folders into your project's `res/` folder: `mipmap-hdpi`, `mipmap-mdpi`, `mipmap-xhdpi`, `mipmap-xxhdpi`, `mipmap-xxxhdpi`, and `mipmap-anydpi-v26` (if it was generated). **Don't copy the `values/` folder**, you'll write your own in Step 5
4. When asked "Replace?", say **YES to all**
5. **Verify:** open one of the mipmap folders and you should see your custom icon files

**If you take Path B, continue to Step 5.**

**What the icon files are:**
- `ic_launcher.png` - Standard square icon (fallback)
- `ic_launcher_round.png` - Round icon (Android 7-11)
- `ic_launcher_foreground.png` - Foreground layer for adaptive icons (Android 8+)
- `mipmap-anydpi-v26/ic_launcher.xml` - Adaptive icon configuration for modern Android
- `values/ic_launcher_background.xml` (Path A only) - The background color the adaptive icon XML references

### Step 5: Create colors.xml for Adaptive Icons

**Only do this step if you took Path B in Step 4.** Path A already gave you `values/ic_launcher_background.xml`, and doing both breaks the build with a duplicate resource error.

The `mipmap-anydpi-v26` folder turns on **adaptive icons** (Android 8+), which look noticeably better than the fallback icons. An adaptive icon is a foreground image plus a background color, and Android masks it to the launcher's shape. The adaptive icon XML references a color called `ic_launcher_background`, so that color has to be defined in `values/`. Without it, the build fails with "resource not found."

**Sanity check first:** open `android/app/src/main/res/values/` in Finder. If `ic_launcher_background.xml` is already there, easyappicon's file snuck in (you probably did Path A by accident). Either delete that file and continue below, or skip this step and go with Path A. Just don't end up with both.

**Create new file:** `android/app/src/main/res/values/colors.xml`

```xml
<?xml version="1.0" encoding="utf-8"?>
<resources>
    <color name="ic_launcher_background">#FFFFFF</color>
</resources>
```

**Use the same color you picked in Step 3:**
- Picked **white**? Keep `#FFFFFF`
- Picked **RIT orange**? Change to `#F76902`

Using your own design? Any hex works (`#000000` black, `#42A5F5` blue, `#4CAF50` green). Pick whatever complements your foreground icon.

---

### Step 6: Update AndroidManifest.xml for Round Icons

Tell Android about the round icon (mainly used on Android 7.1-11).

**File:** `android/app/src/main/AndroidManifest.xml`

**Find this section (around line 7-10):**
```xml
<application
    android:label="icon_splash_demo"
    android:name="${applicationName}"
    android:icon="@mipmap/ic_launcher">
```

**Add the round icon reference:**
```xml
<application
    android:label="icon_splash_demo"
    android:name="${applicationName}"
    android:icon="@mipmap/ic_launcher"
    android:roundIcon="@mipmap/ic_launcher_round">
```

`android:icon` is the standard icon most devices use. `android:roundIcon` is the round one some launchers use, and Android picks between them based on the launcher. On Android 8+, many launchers use adaptive icons instead, so don't worry if you don't see a perfectly circular icon. The standard icon works great.

**Bonus: change the app name.** While you're here, you can change the name that appears under the icon:
```xml
android:label="My Cool App"  <!-- Change from "icon_splash_demo" -->
```

## Part 2: Splash Screens

A splash screen is what shows briefly when your app launches, before the main UI loads. It isn't a Flutter screen. It's a **native** iOS/Android screen, because Flutter takes a moment to start up and can't draw anything until it has. Without one, users stare at a blank white screen while Flutter loads. iOS **requires** a launch screen; Android doesn't, but users expect one.

**Platform differences:**

| Platform | Background Image? | Image in Center? | Branding Image? |
|----------|-------------------|------------------|-----------------|
| **Android 11 and below** | Yes | Yes | Yes |
| **Android 12+** | No (color only) | Yes | Yes |
| **iOS** | Yes | Yes | Yes |

Google changed the rules in Android 12 for a more consistent experience: background images are no longer allowed, only solid colors.

---

### Step 9: Install flutter_native_splash Package

```bash
flutter pub add flutter_native_splash
```

This package generates all the platform-specific splash screen files for you. Doing it by hand means editing XML, storyboards, and asset catalogs on each platform.

---

### Step 10: Prepare Splash Screen Images

The package can show three things: a **background** (color or image), a **center image** (required), and a **branding** image at the bottom (optional). Here's what we'll use:

**1. Center logo: RIT tiger head, pre-sized for splash screens**
- **Download from:** https://people.rit.edu/~jxtadm/IGME340/rit_tiger.png
- Right-click → Save As (save to your Downloads)
- It's already sized for the 640x640 safe zone, so Android 12+'s circular mask won't cut it off (more in Step 15)

**2. Background color: RIT orange (`#F76902`)**
- A solid color works on every platform, including Android 12+

**3. Branding (optional, time permitting): RIT tagline**
- RIT's tagline "Always on to something amazing" at the bottom
- The branding "text" has to be a **PNG image** of text, not real text. Splash screens are native screens that show **before** Flutter loads, so they can't render Flutter widgets, fonts, or strings. Anything you want to show has to already exist as an image.
- Step 11 covers making the image, but feel free to **skip it** to keep moving. It's nice polish; skipping it is totally fine.

---

### Step 11: Copy Splash Logo to Assets Folder

**Create the assets folder (if you haven't already):** in VS Code, right-click your project root → New Folder → `assets`. Then right-click `assets` → New Folder → `images`.

**Copy the logo:** drag `rit_tiger.png` from Step 10 (https://people.rit.edu/~jxtadm/IGME340/rit_tiger.png) into `assets/images/`. It's already named right, so no rename needed.

**Optional: branding text.** Skip this if you're short on time; the tiger alone looks great, and you can add it later. To add the tagline, make a PNG of the text:

1. **Create the image** with any tool: **Canva** (https://canva.com), **Photoshop**, or **PowerPoint** / **Keynote** (export slide as PNG). Quick online option: https://www.kapwing.com/tools/add-text-to-image. **Specs:** 600x240 PNG, transparent background, **white text** (shows well on orange)
2. **Save it** as `rit_tagline.png` in `assets/images/`

**Your structure:**
```
icon_splash_demo/
└── assets/
    └── images/
        ├── rit_tiger.png
        └── rit_tagline.png (optional)
```

**Add to pubspec.yaml:** find the `flutter:` section and add the assets:

```yaml
flutter:
  uses-material-design: true

  assets:
    - assets/images/
```

**Get packages:** press **Cmd+Shift+P** (Mac) or **Ctrl+Shift+P** (Windows), type "Flutter: Get Packages", or click "Get Packages" at the top of pubspec.yaml if it shows up. This tells Flutter to include your images in the app.

---

### Step 12: Create flutter_native_splash.yaml Config File

**Create new file:** `flutter_native_splash.yaml` at the project root, next to pubspec.yaml (right-click project root → New File).

**Without branding text:**

```yaml
flutter_native_splash:
  # RIT orange background for all platforms
  color: "#F76902"

  # RIT tiger logo in center
  image: assets/images/rit_tiger.png

  # Android 12+ specific settings (same as above, but explicit)
  android_12:
    color: "#F76902"  # RIT orange background
    image: assets/images/rit_tiger.png
```

**With the tagline (optional):**

```yaml
flutter_native_splash:
  # RIT orange background for all platforms
  color: "#F76902"

  # RIT tiger logo in center
  image: assets/images/rit_tiger.png

  # RIT tagline at bottom
  branding: assets/images/rit_tagline.png
  branding_mode: bottom

  # Android 12+ specific settings
  android_12:
    color: "#F76902"  # RIT orange background
    image: assets/images/rit_tiger.png
    branding: assets/images/rit_tagline.png
```

`color` is the background and `image` is the center logo. The `android_12:` section repeats the same settings because Android 12+ needs them set explicitly. `branding` adds a small image at the bottom (about 600x240), and `branding_mode: bottom` puts it there. Use the tagline version only if you made `rit_tagline.png` in Step 11.

**Different background color?** Change `#F76902` to any hex, like `"#FFFFFF"` (white), `"#000000"` (black), or `"#42A5F5"` (blue).

### Step 13: Generate Splash Screen Files

```bash
dart run flutter_native_splash:create --path=flutter_native_splash.yaml
```

This reads your config, generates the splash files for Android (XML, drawables) and iOS (storyboard, assets), and updates AndroidManifest.xml and the other platform files.

**You should see output like:**
```
Creating splash screens
  ✓ Android splash screen created
  ✓ Android 12 splash screen created
  ✓ iOS splash screen created
  ✓ Web splash screen created (if applicable)

You're ready to go!
```

**If you get errors:**
- Check that image paths in the YAML are correct
- Verify images exist in `assets/images/`
- Make sure you ran `flutter pub get` after adding assets to pubspec.yaml

**If you change your splash images or config later, run this command again.**

### Step 15: Understanding Image Masking (Android 12+)

On Android 12+, the center image gets masked to a circle. Your 960x960 image is displayed, but only the center 640x640 circle is visible, so corners get cut off. A circle icon fits perfectly; a square icon loses its corners.

The `rit_tiger.png` you downloaded is pre-sized so the tiger sits inside that 640x640 safe zone, which is why nothing important gets cut off.

**Designing your own splash logo (for Project 3):** keep the meaningful content in the center 640x640 of a 960x960 image. When in doubt, design inside a circle, not a square.

### Step 16 (Optional): Control Splash Screen Duration

By default the splash screen disappears as soon as Flutter is ready. To keep it longer:

**1. Import the package in your main.dart:**
```dart
import 'package:flutter_native_splash/flutter_native_splash.dart';
```

**2. Preserve the splash screen at app startup:**
```dart
void main() {
  WidgetsBinding widgetsBinding = WidgetsFlutterBinding.ensureInitialized();
  FlutterNativeSplash.preserve(widgetsBinding: widgetsBinding);

  runApp(const MyApp());
}
```

**3. Remove it when ready (e.g., after loading data):**
```dart
// In your app, after initialization is done:
FlutterNativeSplash.remove();
```

**Example: show the splash for 3 seconds:**
```dart
void main() {
  WidgetsBinding widgetsBinding = WidgetsFlutterBinding.ensureInitialized();
  FlutterNativeSplash.preserve(widgetsBinding: widgetsBinding);

  // Remove after 3 seconds
  Future.delayed(const Duration(seconds: 3), () {
    FlutterNativeSplash.remove();
  });

  runApp(const MyApp());
}
```

**You have to call `FlutterNativeSplash.remove()` at some point**, or the splash screen stays forever and blocks your app.

Use this while you load data from an API, initialize a database, or preload assets. Don't use it just to show off your splash screen longer. Users hate delays!

## Troubleshooting

| Problem | Solution |
|---------|----------|
| **Icons not changing** | Did you rebuild the app? (`flutter run` again) |
| **Build error: ic_launcher_background not found** | You copied mipmap-anydpi-v26 but forgot to create colors.xml (Step 5) |
| **Build error: duplicate resource / "resource already defined"** for `ic_launcher_background` | You have two XML files in `android/app/src/main/res/values/` both declaring the same color. This happens when easyappicon.com's download includes its own `ic_launcher_background.xml` and you also created `colors.xml` in Step 5. Open the `values/` folder, delete `ic_launcher_background.xml`, and keep only `colors.xml`. |
| **Android emulator stuck installing** | Use Chrome instead! Press F5, select Chrome from device list. Android emulators can be slow. |
| **Round icon not showing as circular** | Modern Android (8+) uses adaptive icons, not round icons. Your icon is working correctly! The shape depends on the launcher. |
| **Splash screen not showing** | Close app completely, launch fresh from home screen |
| **Android 12+ shows wrong background** | Check `android_12:` section in YAML has `color`, not `background_image` |
| **Image looks wrong on Android 12+** | Remember circular masking! Keep content in center 640x640 circle |
| **"You're ready to go!" not showing** | Check YAML syntax, verify image paths are correct |
| **Splash screen stays forever** | Did you call `FlutterNativeSplash.remove()`? Must call it! |
| **Icon blurry on some devices** | Use higher resolution source image (1024x1024 minimum) |
| **Bottom branding not showing** | Check `branding` path in YAML, verify image exists |

Each platform has different requirements; that's just how mobile development works.
