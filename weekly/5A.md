### Stack Widget - Layering UI Elements
The Stack widget allows you to overlay multiple widgets on top of each other, similar to absolute positioning in CSS. Think of it like stacking transparent sheets - each child widget is a layer, with the first child at the bottom.

**Key Points:**
- Children are layered in order (first = bottom, last = top)
- Use `Positioned` widget for precise placement within the stack
- `clipBehavior: Clip.none` allows content to overflow stack boundaries
- Perfect for overlapping UI elements like badges on icons or text on images

**Basic Stack Example:**
```dart
Stack(
  alignment: Alignment.center,
  children: [
    Container(color: Colors.red, width: 300, height: 300),    // Bottom
    Container(color: Colors.green, width: 200, height: 200),  // Middle
    Container(color: Colors.yellow, width: 100, height: 100), // Top
  ],
)
```

**Positioned Widget Example:**
```dart
Stack(
  clipBehavior: Clip.none, // Allow overflow
  children: [
    Container(color: Colors.blue, width: 200, height: 200),
    Positioned(
      right: -50,  // Negative values create overflow
      bottom: -50,
      child: Container(
        color: Colors.orange,
        width: 100,
        height: 100,
      ),
    ),
  ],
)
```

### SVG Images in Flutter
SVGs (Scalable Vector Graphics) are resolution-independent images that look crisp at any size. Flutter requires the `flutter_svg` package since SVG support isn't built-in.

**Setup Process:**
1. Install package: `flutter pub add flutter_svg`
2. Add SVG files to `assets/images/` folder
3. Update `pubspec.yaml` with asset declarations
4. Import package: `import 'package:flutter_svg/flutter_svg.dart';`

**Common SVG Issues:**
- Colored SVGs often render as black due to embedded CSS
- Solution: Run the file through the [SVG Inliner](https://internettoolbox.it/tools/svg-inliner/), click **Inline Styles**, then paste the result back over your `.svg` file and restart the app
- Apply colors using `colorFilter` property (not deprecated `color`)

**SVG Implementation Examples:**
```dart
// Basic SVG loading
SvgPicture.asset(
  'assets/images/hand.svg',
  width: 50,
  height: 50,
)

// SVG with color filter (proper method)
SvgPicture.asset(
  'assets/images/hand.svg',
  width: 50,
  height: 50,
  colorFilter: ColorFilter.mode(
    Colors.white,
    BlendMode.srcIn,  // Best for solid color replacement
  ),
)

// Network SVG
SvgPicture.network(
  'https://people.rit.edu/~jxtadm/vite.svg',
  width: 200,
  height: 200,
)
```

### Dialog with Scrollable Content
When your dialog needs to display longer text (like item descriptions in Project 1), you need a scrollable content area inside the dialog. The key pattern uses a Column with `mainAxisSize: MainAxisSize.min` and a Container with a fixed height wrapping a SingleChildScrollView.

**Why `mainAxisSize: MainAxisSize.min`?**
Without it, the Column inside the AlertDialog expands to fill the entire screen height, making the dialog stretch top to bottom. `MainAxisSize.min` tells the Column to shrink-wrap to only the space its children need.

**Scrollable Dialog Pattern:**
```dart
showDialog(
  context: context,
  barrierDismissible: false,
  builder: (context) {
    return AlertDialog(
      title: Text("My Dialog"),
      content: Column(
        mainAxisSize: MainAxisSize.min, // Critical!
        children: [
          Text("Stuff Here"),
          Container(
            height: 50, // Fixed height creates the scrollable area
            child: SingleChildScrollView(
              child: Text(lorem),
            ),
          ),
          ElevatedButton(
            onPressed: () {
              Navigator.pop(context);
            },
            child: Text("Close"),
          ),
        ],
      ),
    );
  },
);
```

**Key Points:**
- `mainAxisSize: MainAxisSize.min` on the Column prevents it from stretching
- Container with a fixed `height` limits the scrollable area
- SingleChildScrollView inside the Container makes the text scrollable
- Close button can go inside `content` (Column) or in `actions` — either works
- `barrierDismissible: false` forces users to use the close button (recap from 4B)

## Key Concepts & Terminology

| Term | Definition |
|------|------------|
| Stack | Widget that layers children on top of each other |
| Positioned | Widget for precise placement within a Stack |
| SVG | Scalable Vector Graphics - resolution-independent images |
| clipBehavior | Controls content clipping at widget boundaries |
| BlendMode.srcIn | Color filter mode that replaces existing colors |
| mainAxisSize | Controls how much space a Column/Row takes along its main axis |
| MainAxisSize.min | Shrink-wraps the Column/Row to fit its children (no stretching) |

## Common Issues & Solutions

| Problem | Solution |
|---------|----------|
| SVGs render as black | Run the file through the SVG Inliner, or apply colorFilter |
| Stack content clips | Set `clipBehavior: Clip.none` on Stack |
| Positioned widget not working | Must be direct child of Stack |
| Dialog stretches full screen | Add `mainAxisSize: MainAxisSize.min` to the Column inside dialog content |
| Content not scrolling in dialog | Wrap text in SingleChildScrollView inside a Container with fixed height |

## Key Takeaways

1. **Stack enables complex layouts** - Essential for overlapping UI elements like badges, overlays, and layered designs
2. **SVGs need special handling** - The flutter_svg package is required, and color issues are common but fixable
3. **Dialogs with long content need scrollable areas** - Use Column + `mainAxisSize: MainAxisSize.min` + Container with SingleChildScrollView
4. **Always test overflow behavior** - Stack with Positioned widgets can easily overflow - use clipBehavior wisely
