### Button States and setState
We explored how Flutter manages UI updates through state management, starting with the fundamental `setState` method.

**What We Did:**
- Created three buttons with counters
- Implemented button press functions that modify variables
- Discovered that UI doesn't update without `setState`
- Wrapped our state changes in `setState(() { })` to trigger rebuilds
- Demonstrated that setState rebuilds the entire widget tree

### Advanced App Bar Customization
The app bar is more than just a title - we transformed it into a rich UI element with multiple interactive components.

**What We Did:**
- Changed background color using `Color.fromARGB(255, r, g, b)`
- Adjusted elevation for shadow effects
- Added leading widget (left side) with custom icon styling
- Implemented action buttons (right side) with multiple IconButtons
- Removed the debug banner with `debugShowCheckedModeBanner: false`
- Applied shadows, colors, and padding to icons

### Working with Images
Images are essential for rich UIs, but require proper configuration. We covered both local and network images.

**Local Images:**
- Created `assets/images/` folder structure (OUTSIDE lib folder)
- Configured `pubspec.yaml` with proper indentation (tabs, not spaces!)
- Used `AssetImage('assets/images/filename.png')` to load images

**Network Images:**
- Used `Image.network(url)` for internet-based images
- Handled common connection issues (airplane mode, emulator problems)
- Learned when to cold boot the emulator

### BoxDecoration for Advanced Styling
We transformed plain containers into rich, styled elements using BoxDecoration.

**What We Did:**
- Added borders with customizable width and color
- Applied border radius for rounded corners
- Created shadows with blur and offset
- Embedded images as decoration backgrounds
- **Important:** Cannot have color in both Container AND BoxDecoration

## Key Concepts & Terminology

| Term | Definition |
|------|------------|
| setState | Method that triggers UI rebuild when state changes |
| Hot Reload | Instantly updates UI without losing app state |
| AssetImage | Widget for loading images from local project files |
| NetworkImage | Widget for loading images from URLs |
| BoxDecoration | Container styling including borders, shadows, gradients |
| pubspec.yaml | Configuration file that defines project dependencies and assets |
| Cold Boot | Complete restart of emulator to fix connection issues |
| Leading Widget | Widget displayed before the title in app bar (typically left side) |
| Actions | List of widgets displayed after title in app bar (typically right side) |

## Common Issues & Solutions

| Problem | Solution |
|---------|----------|
| UI changes but doesn't update on screen | Wrap your state changes in `setState(() { })` |
| Images don't display | Check pubspec.yaml indentation and assets path |
| Network image shows error | Check airplane mode, cold boot emulator if needed |
| Container color conflict error | Remove color from Container if using BoxDecoration |
| Overflow error (yellow/black stripes) | Wrap Column in SingleChildScrollView |
| Project submission is 600MB+ | Run `flutter clean` before zipping |
| Hot reload crashes with font changes | Do a full restart instead of hot reload |

## Key Takeaways

1. **setState is crucial** - Without it, your UI will never update even when variables change
2. **Asset configuration is fragile** - One wrong space in pubspec.yaml breaks everything
3. **Network resources have tradeoffs** - More flexible but can fail without internet
