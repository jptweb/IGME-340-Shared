### Multiplatform Development
- **The Problem**: Different platforms require different languages (iOS: Swift, Android: Kotlin, Web: JavaScript)
- **The Promise**: Write once, deploy everywhere
- **The Reality**: Trade-offs between native performance and development efficiency

### Why Flutter?
- 46% of mobile developers use Flutter (2022)
- Single codebase for iOS, Android, Web, Desktop
- Hot reload for rapid development
- Strong community and Google backing

### Dart Basics
```dart
// Variables and types
int age = 21;
double gpa = 3.5;
String name = "Flutter Dev";
bool isAwesome = true;

// String interpolation
print("Hello $name!");
print("Age next year: ${age + 1}");

// Constants
final currentYear = 2025;    // Set at runtime
const pi = 3.14159;         // Set at compile time
```
