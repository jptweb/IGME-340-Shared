# Week 2B - Flutter Development Fundamentals

## What We Covered in Class

### VS Code Project Setup & Troubleshooting
We started by creating empty Flutter applications and dealing with common simulator issues that arise when developing multiple projects.

**Key Points:**
- Use Command Palette (`Cmd/Ctrl + Shift + P`) for creating Flutter projects
- Always choose "Empty Application" template after this week
- NEVER use spaces in project paths - use underscores instead
- Simulator storage issues are common when testing multiple projects

### Widget Manipulation & Shortcuts
Learned essential VS Code shortcuts that significantly speed up Flutter development.

**What We Did:**
- Used `Cmd/Ctrl + Period` to access widget manipulation menu
- Practiced removing, wrapping, and extracting widgets
- Used the `stfu` snippet to quickly create StatefulWidgets
- Applied `Alt/Shift + F` for auto-formatting with trailing commas

### Code Organization Techniques
Explored three methods to extract and organize complex widget trees for better maintainability.

**Key Points:**
- Extract Method: Creates a function in the same class
- Extract Local Variable: Creates a variable in build method
- Extract Widget: Creates a new widget class (best for reusable components)

### Flutter Debugging
Set up and used debugging tools in both VS Code and Chrome DevTools.

**What We Did:**
- Set breakpoints in the counter app's `_incrementCounter()` method
- Used debug console to inspect variables
- Opened Chrome DevTools with "Dart: Open DevTools in Browser"
- Learned to recognize when app is paused vs frozen

## Key Concepts & Terminology

| Term | Definition |
|------|------------|
| StatelessWidget | Static widget with no mutable state |
| StatefulWidget | Interactive widget that can change over time |
| BuildContext | Flutter's reference to widget location in tree (like DOM) |
| setState() | Method that triggers UI rebuild when state changes |
| Hot Reload | Instantly updates UI while preserving app state |
| Hot Restart | Restarts app but faster than full rebuild |
| Widget Tree | Hierarchical structure of all widgets in app |
| Trailing Comma | Comma after last parameter that enables auto-formatting |

## Common Issues & Solutions

| Problem | Solution |
|---------|----------|
| "Insufficient storage space" on simulator | Android Studio → Virtual Device Manager → Wipe Data |
| `const` errors after modifications | Remove const keyword from parent widget |
| App seems frozen | Check if debugger is paused (look for "Paused" indicator) |
| Hot reload not updating | Try hot restart, or stop and rebuild completely |
| Widget menu not appearing | Click directly on widget name, not inside parameters |
| Code won't format properly | Add trailing commas after all closing parentheses |
| Can't find available properties | Use `Ctrl + Space` to see suggestions |

## Key Takeaways

1. **Master VS Code shortcuts** - They'll save you hours of development time
2. **Always use trailing commas** - Essential for proper code formatting
3. **Extract complex widgets** - Keeps code readable and maintainable
4. **Check pause status when debugging** - Most "frozen" apps are just paused
5. **`flutter clean` before submitting** - Projects grow from 1MB to 450MB+ after building
