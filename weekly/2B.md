## I. Creating an Empty Application

### Why "Empty Application"?

Last class we used "Application" template (with the counter example). Going forward, use "Empty Application" - it gives you a clean slate:

**Command Palette (Cmd/Ctrl + Shift + P):**
1. Type "Flutter: New Project"
2. Select **"Empty Application"**
3. Choose location and name

This gives you just the essentials:
```dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MainApp());
}

class MainApp extends StatelessWidget {
  const MainApp({super.key});

  @override
  Widget build(BuildContext context) {
    return const MaterialApp(
      home: Scaffold(
        body: Center(
          child: Text('Hello World!'),
        ),
      ),
    );
  }
}
```

## II. VS Code Shortcuts for Flutter

These shortcuts will save you hours. Practice them until they're muscle memory!

### Quick Actions Menu (Cmd/Ctrl + .)

Click on any widget name, then press `Cmd/Ctrl + .` to access:
- **Wrap with widget...** - Surround with a new parent widget
- **Remove this widget** - Delete widget, keep children
- **Extract Widget** - Create a new widget class
- **Extract Method** - Create a function returning the widget

### Widget Snippets

Type these abbreviations and press Tab:

| Snippet | Creates |
|---------|---------|
| `stless` | StatelessWidget template |
| `stful` | StatefulWidget template |
| `stfu` | Shorter StatefulWidget template |

### Essential Shortcuts

| Shortcut | Action |
|----------|--------|
| `Cmd/Ctrl + .` | Quick actions menu |
| `Alt/Option + Shift + F` | Auto-format code |
| `Cmd/Ctrl + Space` | Show available properties |
| `Cmd/Ctrl + Shift + R` | Rename symbol everywhere |
| `F2` | Rename (same as above) |

### The Trailing Comma Trick

**Always add trailing commas** after the last parameter. This enables proper auto-formatting:

```dart
// Without trailing comma - formats on one line (hard to read)
Container(color: Colors.red, height: 100, width: 100)

// With trailing comma - formats nicely
Container(
  color: Colors.red,
  height: 100,
  width: 100,  // <-- trailing comma
)
```

Press `Alt/Option + Shift + F` to auto-format.

> **⚠️ Dart 3.8+ Note:** Recent versions of Dart changed the formatter so it decides line breaks for you, which can override your trailing commas. To restore the "I control the commas" behavior, add this to your project's `analysis_options.yaml`:
> ```yaml
> formatter:
>   trailing_commas: preserve
> ```
> This keeps the trailing comma behavior described above working as expected.

## III. StatelessWidget vs StatefulWidget

### StatelessWidget
- **Static** - doesn't change after being built
- Used for: labels, icons, static layouts
- No `setState()` method

```dart
class MyLabel extends StatelessWidget {
  const MyLabel({super.key});

  @override
  Widget build(BuildContext context) {
    return const Text('I never change');
  }
}
```

### StatefulWidget
- **Dynamic** - can change and rebuild
- Used for: counters, forms, anything interactive
- Call `setState()` to trigger rebuild

```dart
class MyCounter extends StatefulWidget {
  const MyCounter({super.key});

  @override
  State<MyCounter> createState() => _MyCounterState();
}

class _MyCounterState extends State<MyCounter> {
  int count = 0;

  @override
  Widget build(BuildContext context) {
    return Column(
      children: [
        Text('Count: $count'),
        ElevatedButton(
          onPressed: () {
            setState(() {
              count++;
            });
          },
          child: const Text('Add'),
        ),
      ],
    );
  }
}
```

### The Key Rule

**`setState()` tells Flutter to rebuild the widget.** Without it, your UI won't update even if variables change.

## IV. Building a Simple App Together

Let's build a greeting app step by step:

### Step 1: Start with Empty Application
Create a new empty Flutter project called `greeting_app`.

### Step 2: Add a Scaffold with AppBar
Replace the body of `MaterialApp`:

```dart
return MaterialApp(
  home: Scaffold(
    appBar: AppBar(
      title: const Text('Greeting App'),
    ),
    body: const Center(
      child: Text('Hello!'),
    ),
  ),
);
```

### Step 3: Convert to StatefulWidget
We need state to track who we're greeting. Use the `stful` snippet or Quick Actions to convert.

### Step 4: Add a Button to Change the Greeting
```dart
class _MainAppState extends State<MainApp> {
  String name = 'World';

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: Scaffold(
        appBar: AppBar(
          title: const Text('Greeting App'),
        ),
        body: Center(
          child: Column(
            mainAxisAlignment: MainAxisAlignment.center,
            children: [
              Text(
                'Hello, $name!',
                style: const TextStyle(fontSize: 24),
              ),
              const SizedBox(height: 20),
              ElevatedButton(
                onPressed: () {
                  setState(() {
                    name = name == 'World' ? 'Flutter' : 'World';
                  });
                },
                child: const Text('Change Name'),
              ),
            ],
          ),
        ),
      ),
    );
  }
}
```

### Step 5: Use Hot Reload
Save and watch it update instantly. Try changing colors, text sizes, and button labels.

## V. Debugging in Flutter

### Setting Breakpoints

1. Click in the gutter (left of line numbers) to set a breakpoint
2. Run in debug mode (F5)
3. App pauses when it hits the breakpoint
4. Use debug panel to:
   - Step through code
   - Inspect variables
   - Continue execution

### Common Debugging Scenario

Set a breakpoint inside your `setState()` call:
```dart
onPressed: () {
  setState(() {
    name = name == 'World' ? 'Flutter' : 'World';  // <-- breakpoint here
  });
},
```

When you tap the button, execution pauses. You can:
- See the current value of `name`
- Step through the assignment
- Continue to see the UI update

### "App is Frozen" Troubleshooting

If your app seems frozen, check if it's actually **paused at a breakpoint**:
- Look for "Paused" in the debug toolbar
- Check the Debug Console panel
- Press Continue (F5) or remove breakpoints

## VII. Common Issues & Solutions

| Problem | Solution |
|---------|----------|
| `const` errors after modifications | Remove const keyword from parent widget |
| Hot reload not updating | Use Hot Restart (`Cmd/Ctrl + Shift + F5`) |
| Widget menu not appearing | Click on widget name, not inside parentheses |
| Code won't format | Add trailing commas, then `Alt + Shift + F` |
| App seems frozen | Check if debugger is paused |
| "Insufficient storage" on emulator | Android Studio > Virtual Device Manager > Wipe Data |
